# III-1-03 알고리즘의 이해와 표현 수업 설계

교과서(비상교육) 100~102쪽 / 폴더 `03-algorithm-programming/03-expression`

## 1. 개념적 렌즈

**렌즈:** 추상화(abstraction) — Ⅲ-1 네 소단원이 공유한다(01 설계에서 확정,
축 배분표는 `01-problem-state/lesson.md` 1번).

**이 단원이 맡은 축:** 남긴 것을 **어떤 형식으로 적어야** 남이 그대로 실행하는가.

**왜 이 축인가 — 01·02와의 경계.** 01·02의 학생은 문제를 보는 쪽이었다 —
판을 적고, 벗기고, 숫자를 관찰했다. 03의 학생은 처음으로 **쓰는 쪽**이 된다.
02가 끝난 학생 손에는 자기만 알아보는 「내 풀이 메모」가 있는데, 그것은 남이
실행할 수 없다. 「나만 알아보면 된다」에서 「남이 — 끝내는 컴퓨터가 — 그대로
실행할 수 있어야 한다」로 넘어가는 단원이다.

| | 01 문제의 상태 | 02 문제의 추상화 | 03 알고리즘 표현 |
|---|---|---|---|
| 질문 | 이 판이 어느 판인지 **정해지는가** | 이 문제를 여전히 **풀 수 있는가** | 이 순서를 누가 실행해도 **같아지는가** |
| 조작의 방향 | 정보를 골라 **담기** | 문제에서 **벗기기** | 명령을 **늘어놓기** |
| 핵심 피드백 | 담아도 안 줄어드는 카드 (무반응) | 벗겨도 안 변하는 숫자 (무반응) | 같은 대본인데 **갈라지는 자취** (어긋남) |

01·02의 핵심 피드백이 무반응이었다면 03은 처음으로 **어긋남**이다 — 학생이
만든 것이 실행하는 이에 따라 다르게 굴러가는 것을 본다.

**02에서 넘겨받은 것 셋.** ①벗겨낸 알맹이(옮기는 이 1 + 대상 3 + 금지 쌍 2 +
한 번에 하나) — 02의 2차시에서 '핵심 요소'라는 이름을 얻었고, 03의 명령 카드
어휘가 정확히 이것만으로 이루어진다. ②1차시 학습지의 「내 풀이 메모」 —
1차시 도입 훅과 활동 4(번역)에서 쓴다. ③상태 변화 기록표 — 01이 일부러 뺐던
그 표가 이 앱의 「실행 자취」로 제자리를 찾는다(5번 참고).

**04에 넘겨줄 것:** 그대로 실행되는 대본이 여럿 생긴다(사람마다 순서가 달라도
같은 도착). 「그중 어느 것이 더 좋은가」는 04의 축이라 03에서는 묻지 않는다 —
03은 "누가 실행해도 같은가"까지만 간다.

## 2. 일반화 문장

**일반화 1 (본체):** 실행하는 이가 스스로 정할 것이 남지 않도록 약속된
표현으로 순서를 적어야, 누가 실행해도 과정과 결과가 같아진다.

(「결과」만 말하지 않고 「과정과 결과」로 적는 이유 — 「전부 옮긴다」 한 장이면
두 로봇 다, 순서는 달라도 빨간 표시를 남기며, 모두 건너간 판에 닿는다.
"결과는 같잖아요"라는 영리한 반례가 나올 수 있는 구조이고, 그 사례는 2차시
정리에서 토론감으로 쓴다.)

**일반화 2 (보조, 전이 단계에서):** 정확한 표현이 보장하는 것은 「같은 실행」
까지이고, 그 풀이가 좋은지는 다른 물음이다.

**점검**

- [x] 다른 단원이나 다른 교과에도 통하는가 — 일반화 1: Ⅲ-2 프로그래밍
  (프로그래밍 언어가 곧 '약속된 표현', 컴퓨터가 곧 '해석하지 않는 실행자'),
  04(비교하려면 먼저 두 풀이가 그대로 실행되게 적혀 있어야 한다), 악보,
  요리 레시피(베이킹의 그램 단위), 과학 실험 절차, 응급처치 매뉴얼.
  일반화 2: 04로 직결 — 그대로 실행되는 두 대본 중 어느 쪽이 좋은가는
  별도의 기준이 필요하다는 예고
- [x] 특정 도구나 프로그램 이름이 들어가 있지 않은가
- [x] "무엇이다"가 아니라 관계를 진술하는가 — "~해야 ~가 같아진다" /
  "~가 보장하는 것은 ~까지이고, ~는 다른 물음이다"

## 3. 탐구 질문

| 종류 | 질문 |
|---|---|
| 사실적 (답이 정해진 것) | 정확한 카드만으로 강 건너기를 끝내면 명령은 몇 장인가? 애매한 카드 5장 중 로봇 A와 B를 실제로 갈라놓은 카드는 몇 장이었나? |
| 개념적 (일반화로 이끄는 것) | 같은 카드 줄을 받았는데 두 로봇의 결과가 달라졌다면, 고칠 곳은 로봇인가 대본인가? 사람끼리는 통하던 메모가 왜 로봇에게는 통하지 않는가? |
| 논쟁적 (정답이 갈리는 것) | 애매한 명령이 이번에 같은 결과를 냈다면 다음에도 믿고 써도 되는가? 사람에게 주는 설명도 로봇에게 주듯 빈틈없이 적어야 하는가? |

**「어느 대본이 더 좋은가」류의 비교 질문은 여기서 다루지 않는다.** 그것은
04의 축이다. 명령 수를 세어 줄을 세우는 순간 03이 04를 침범한다.

## 4. 관련 성취기준

- [9정03-02] 문제 해결을 위한 추상화의 중요성을 이해하고, 핵심요소를 중심으로
  알고리즘을 표현한다.

**이 기준은 02와 03이 나눠 맡는다**(01 설계에서 확정, 근거는
`01-problem-state/lesson.md` 4번). 03은 뒷부분 **「핵심요소를 중심으로
알고리즘을 표현」** 담당. 명령 카드의 어휘가 02가 남긴 핵심 요소뿐이라 —
옮기는 이, 대상 셋, 배(한 번에 하나) — 학생은 표현을 만드는 동안 내내 핵심
요소만으로 말하게 된다. 2차시 용어 연결에서 이 대응을 명시한다.

## 5. 앱이 담당할 것

이 단원의 앱은 **「누가 해도 똑같을까?」** 하나다. 소재는 강 건너기 세 번째
사용(01 판을 적기 → 02 문제를 벗기기 → 03 푸는 순서를 적기). **퍼즐을 푸는
앱이 아니라 대본을 실행시켜 보는 앱**이다.

### 화면 구성

한 화면. 위에 01·02와 같은 강 건너기 판(16가지 공간 그대로 — 다만 **표시
전용**, 직접 조작 없음), 아래에 **명령 줄**(빈 칸 10개)과 **명령 카드 9장**.
카드를 줄에 끼우거나 빼면 — 같은 카드를 여러 번 쓸 수 있다 — **로봇 A와
로봇 B가 같은 줄을 처음 판부터 각자 다시 실행**하고, 로봇마다 한 줄씩
**실행 자취**가 즉시 다시 그려진다. 실행 버튼 없음. 자취 끝에는 목표 판이
나란히 있어 마지막 판과 눈으로 비교할 수 있다(같다/다르다 문구는 없다).

**자취의 단위는 명령이 아니라 「배가 한 번 건넘」이다** — 「옮긴다」류는 판
1개, 「갔다 온다」는 2개가 찍히고, 어느 명령이 만든 판들인지 자취 위에 묶음
표시로 보여준다. 명령 단위로 찍으면 「갔다 온다」처럼 제자리로 돌아오는
명령에서 두 로봇이 다르게 움직였는데도 끝 판이 같아 갈라짐이 자취에 안
남는다(설계 검토에서 발견한 구멍). 건넘 단위여야 어떤 해석 차이도 숨지
못하고, 정확 카드 완주 대본의 자취가 정확히 **7번 건넘** — 02의 「가장 짧은
풀이 7번」 — 이 되어 앞 단원의 숫자를 자취에서 다시 만난다. 상태 변화
기록표의 뜻("배가 건널 때마다 상태가 바뀐다")과도 일치한다.

### 명령 카드 9장 (섞어 배치, 구분 표시 없음)

| 카드 | 로봇이 하는 일 |
|---|---|
| 늑대를 옮긴다 | A·B 항상 동일 — 배 있는 쪽의 늑대를 태워 건너가 내린다 |
| 염소를 옮긴다 | A·B 항상 동일 |
| 양배추를 옮긴다 | A·B 항상 동일 |
| 빈 배로 건넌다 | A·B 항상 동일 — 아무도 안 태우고 건넌다 |
| 하나 옮긴다 | **로봇마다 다름** — 무엇을? (대상이 없다) |
| 위험한 것을 옮긴다 | **로봇마다 다름** — '위험'의 기준이 없다 |
| 남은 것을 옮긴다 | **로봇마다 다름** — 남은 것이 여럿이면? |
| 갔다 온다 | **로봇마다 다름** — 태우고? 빈 배로? |
| 전부 옮긴다 | **로봇마다 다름** — 결과만 적혀 있고 순서가 없다 |

애매한 카드 다섯 장은 애매함의 종류가 저마다 다르다(대상 없음 / 기준 없음 /
상황 의존 / 동작 묶음 / 결과만 진술). 각 로봇의 해석 규칙은 **화면 어디에도
설명하지 않고**, 로봇마다 다르되 **각 로봇 안에서는 언제나 일관**(무작위
아님)이다. 규칙의 구체 내용은 코드 탭에서 확정하되 두 조건만 지킨다 —
①정확 카드 4장은 두 로봇이 완전히 같게 ②애매 카드 5장은 저마다 두 로봇의
해석이 실제로 갈라질 수 있게.

### 실행 규칙 둘 — 나중에 교과서 용어와 일대일로 만난다

- **규칙 위반**(농부 없는 쪽에 늑대+염소, 염소+양배추)은 그 자취 판에 빨간
  표시만 하고 **계속 실행**한다(01의 「막지 않는다」 원칙 그대로). **위반이
  판의 상태를 바꾸지는 않는다** — 잡아먹힘을 모델링하지 않고 표시만 남기며,
  판은 16가지 공간 안에서 그대로 계산한다(01·02 앱과 같은 해석. 코드 탭에서
  임의로 캐릭터를 없애거나 실행을 막지 말 것).
  → 2차시에서 "정확하게 적힌 틀린 계획도 있다"(일반화 2)의 근거
- **실행 불가능**(그 자리에 없는 것을 옮기라고 함)은 그 칸에서 **멈춘다** —
  ⛔ 표시, 뒤 명령은 실행하지 않는다. → 교과서의 '수행 가능성'
- **두 자취가 처음으로 달라지는 칸에 표시**가 붙는다. → 교과서의 '명확성'

### 조작 대상

명령 카드를 명령 줄에 **늘어놓기**(끼우기·빼기·순서 바꾸기). 다른 조작은
없다. 자취의 작은 판을 누르면 그 판이 위의 큰 판에 크게 보이는 것만
허용한다(확인용).

### 즉시 보이는 변화

카드를 끼우거나 빼는 순간 두 로봇의 자취 전체가 다시 그려진다. 애매 카드가
하나라도 끼면 대개 두 자취가 어딘가에서 갈라지고, 정확 카드뿐이면 어떤
배열이든 — 목표에 닿든 위반이 나든 — 두 자취가 끝까지 완전히 같다.

### 학생이 하는 판단

1. **갈라진 지점 짚기** — 두 자취가 처음 달라진 칸이 어느 카드 때문인지,
   두 로봇이 각각 무엇을 했는지 읽어낸다
2. **바꿔치기** — 애매한 카드를 어떤 정확한 카드(들)로 바꾸면 같아지는지
   스스로 정해 확인한다
3. **내 메모 번역하기** — 02 학습지의 「내 풀이 메모」를 명령 카드로 옮기고,
   카드로 옮겨지지 않는 말(= 내 메모의 애매한 부분)에 동그라미 친다.
   **02에서 메모를 못 남긴 학생**(퍼즐을 못 풀어 대체 과제를 했던 학생)은
   도입의 가상 메모를 대신 번역한다 — 재료가 없는 학생이 생기지 않게
4. **갈라지는 대본 만들기** (빨리 끝낸 학생용) — 로봇 A는 목표에 닿는데 B는
   못 닿는(또는 그 반대) 대본을 일부러 설계한다. 01의 출제자 틀, 02의 열 번째
   카드에 해당하는 흡수 장치이고, 2차시 모둠 공유의 첫 순서다

### 극단값

빈 명령 줄(자취는 처음 판 하나) ↔ 애매 카드만 10칸(거의 확실히 갈라지거나
멈춤) ↔ 정확 카드만 7장(옮기기 5 + 빈 배 2 — 완주, 자취는 7번 건넘으로 두 줄
완전 일치) ↔ 정확 카드로 짠 **틀린** 대본(두 로봇이 똑같이 틀린다 — 갈라짐
없이 빨간 표시만 같은 자리에. 일반화 2의 근거) ↔ **「전부 옮긴다」 한 장**
(두 로봇 다, 순서는 달라도 빨간 표시를 남기며 모두 건너간 판에 닿는다 —
"결과만 같으면 같은 실행인가?"의 재료, 2차시 정리에서 다룬다).

덤 — 애매한데도 **우연히 같은** 경우가 생긴다(염소만 남았을 때 「하나
옮긴다」는 두 로봇 다 염소일 수밖에 없다). "한 번 같았으면 믿어도 되는가"
논쟁적 질문의 근거이므로, 이 경우를 버그로 알고 없애지 말 것.

### 앱이 하지 않을 것 (개발 탭에서 임의로 넣지 말 것)

- **로봇 A·B의 해석 규칙을 화면에 설명하지 않는다.** 갈라짐 자체가 발견 대상
- **정확/애매를 색·그룹·배치로 구분하지 않는다.** 섞어 둔다 — 01·02의 카드
  배치 원칙과 동일
- **성공·실패·정답 판정 문구를 넣지 않는다.** 자취 끝에 목표 판을 나란히 둘
  뿐, 같은지 판단은 학생 몫
- **명령 수 세기·최단 표시·점수·힌트 없음** — 「더 짧게」는 04의 것. 명령 줄
  칸이 10개인 것 자체가 유일한 상한
- **애매 카드를 무작위로 실행하지 않는다** — 로봇마다 결정적. 무작위면 "같은
  로봇도 매번 다름"이 되어 「실행하는 이마다 다르다」는 발견이 흐려진다
- **판 직접 조작 없음**(태우기·건너기 손 조작은 01·02 앱의 것 — 03의 조작은
  명령 카드 하나). 자동 풀이, 단계 잠금, 저장 없음
- **자취를 애니메이션으로 재생하지 않는다** — 모든 단계가 한 번에 보이는
  정지 그림이어야 갈라진 칸을 눈으로 찾을 수 있다
- **'알고리즘', '순서도', '명확성', '수행 가능성' 용어를 화면에 쓰지 않는다.**
  용어는 2차시 정리에서 학생 표현에 이름을 붙이며 처음 등장한다. '상태·핵심
  요소'(01·02에서 이미 배움)와 '명령·로봇' 같은 일상어는 써도 된다
- 성취기준 번호, 교과서 쪽수, 개념 설명 카드를 화면에 두지 않는다

### 조작 어휘

03의 조작은 **「명령 카드를 늘어놓다(끼우다/빼다)」** — 앱 화면·학습지·지도안
공통. 01 「(정보 카드를) 선택하다」, 02 「(바꾸기 카드를) 켜다/끄다」와 겹치지
않게 한다.

### 기존 앱 재사용

01·02 앱의 판 그리기·미니 판·규칙 검사·이모지·터치 조작·초점 복원을
가져온다. 새로 만드는 것은 명령 줄, 로봇 두 대의 실행기(카드별 해석 규칙),
자취 두 줄 — 판이 16가지뿐이라 실행은 단순한 상태 전이 계산이고 외부
라이브러리가 필요 없다. 교사의 제미나이 앱(개인 보관)에 있는 「상태 변화
기록표」 원본은 자취의 시각 형태를 잡을 때 참고한다(코드 탭에서 첨부).

### 게시 순서 주의

이 앱의 실행 자취는 **01이 일부러 뺀 상태 변화 기록표**이고, 완성된 대본은
곧 풀이 공개다. 01·02를 마치지 않은 반에 링크를 먼저 주지 않는다 — **02
수업까지 끝낸 반에만** 클래스룸으로 안내한다(01→02→03 체인 유지).

**첫 페이지 카드 표기:** 학생용 첫 페이지 카드의 단원 표기는 01·02와 같이
**「강 건너기」**, 앱 이름은 「누가 해도 똑같을까?」 — 소단원명에 '알고리즘'이
들어 있어 발견 전에 용어를 주지 않는 원칙에 따라 쓰지 않는다. **1차시
클래스룸 과제의 제목·본문에도 '알고리즘'을 쓰지 않는다**(용어는 2차시 용어
연결에서 처음).

## 6. 수업·클래스룸이 담당할 것

| 단계 | 어디서 | 내용 |
|---|---|---|
| 관계 맺기 | 수업 | 교사가 로봇 노릇 — **가상 메모**(전형적인 애매 문장으로 교사가 미리 제작: "염소 먼저. 그담에 늑대 갖다 놓고 염소 다시. 나머지 옮기면 끝" 수준)를 화면에 띄우고 문자 그대로 실행하다 계획된 지점에서 엉뚱하게 간다. **시연 무대는 판 조작이 열려 있는 02 앱을 투사해서**(또는 칠판 그림) — 03 앱의 판은 표시 전용이라 손으로 실행할 수 없다. "적힌 대로만 했는데?" **구두 4분.** 실제 학생 메모는 쓰지 않는다(노출 부담, 동의 문제). 이어서 02가 심어 둔 훅 회수 — "네 메모라면 로봇이 그대로 실행할 수 있을까?" |
| 조사하기 | 앱 | 위 5번 (자유 대본 → 카드 낱장 예상·확인 → 똑같이 끝내기 → 내 메모 번역) |
| 패턴 말하기 | 클래스룸(1차시) → 패들렛(2차시) | 1차시는 학습지에 개인 기록. 2차시에 모둠 문장을 패들렛 셸프(모둠별 칼럼)에 |
| 정리 | 수업 | 패들렛 문장 → 일반화 1로 다듬기. 다듬는 중에 **「전부 옮긴다」 사례를 꺼낸다** — 두 로봇 다 모두 건너간 판에 닿았지만 과정이 다르고 빨간 표시가 남았다. "결과만 같으면 같은 실행인가?" — 「과정과 결과」가 문장에 들어가야 할 이유를 학생이 말하게. **그다음에** 교과서 100~102쪽 용어 연결 — 갈라짐 = 명확성이 없다, 멈춤 = 수행 가능성이 없다, 명령 줄 = 알고리즘, 자취 = 상태가 바뀌어 온 기록(01 일반화 2 "문제 해결은 상태를 바꾸어 가는 과정"의 회수), 카드 어휘 = 핵심 요소(02 회수). 우리 카드 줄을 교과서의 표현 형식들(자연어·순서도 등) 옆에 놓고 "우리 것은 어느 쪽에 가까운가" |
| 전이 | 수업 | 레시피의 "적당히" vs 베이킹의 그램(3분) → 일상 절차 하나(라면 끓이기 등)를 **학급이 함께 칠판에서** 사각형+화살표 순서도로 옮기기(5분 — 교사가 학생 말을 받아 그린다. 분기 마름모는 소개만, 본격 사용은 Ⅲ-2에서. 개인 연습은 과제 질문 3의 선택지로 — 2차시에 학습지가 없으므로 공책 등 새 기록처를 만들지 않는다) → 일반화 2와 04 예고: "이제 그대로 실행되는 대본이 여럿인데, 어느 게 더 좋지?"(1분) → 과제 질문 3 안내(1분) |

**도구는 차시당 둘까지.** 1차시 = 앱 + 클래스룸(학습지), 2차시 = 패들렛 +
클래스룸. 01·02와 같은 배치 — 기록이 남아야 하는 것은 2차시 모둠 문장부터.

**표현 형식을 다루는 방식** — 형식(자연어·순서도 등)을 1차시에 가르치면
형식이 목적이 된다. 1차시 경험이 교과서의 알고리즘 조건과 이미 일대일이므로
(갈라짐=명확성, 멈춤=수행 가능성), 2차시에 이름만 붙인다. 성취기준의 「표현」은
세 곳에서 채운다: 명령 카드 줄(1차시) · 순서도 맛보기(2차시 전이) · 레시피
고쳐 쓰기(과제 질문 3).

**학습지 규칙** (1차시 1종만, 2차시 학습지 없음 — 02 방식):
활동 칸은 기록, 질문은 해석만(같은 것을 두 번 쓰게 하지 않는다).

- 활동 1 자유 대본 — 처음 만든 대본에 쓴 카드 이름과, 두 로봇이 같았는지 /
  갈라졌다면 몇 번째 칸이었는지 기록
- 활동 2 카드 낱장 표(9장, **앱 화면과 같은 순서** — 종류가 드러나지 않게,
  분류 열 없음) — 끼우기 전에 「갈라질까 / 끝까지 같을까」 예상 + 까닭 한 줄
  → 확인 결과. 02의 예상 표와 같은 리듬
- 활동 3 고쳐 쓰기 — 애매 카드가 든 대본(내 활동 1 대본. 그것이 이미 정확
  카드뿐이었다면 짝의 갈라진 대본이나 도입 가상 메모를 옮긴 대본)을 정확
  카드로 바꿔 **빨간 표시 없이, 자취가 끝까지 같게, 목표 판까지** 만들기.
  무엇을 무엇으로 바꿨는지와 완성 대본의 카드 목록을 기록. 장수도 적되 몇
  장이 좋은지는 묻지 않는다(04의 것). 성공 기준에 「빨간 표시 없이」가
  없으면 「전부 옮긴다」 한 장이 이 활동의 답이 되어버린다
- 활동 4 내 메모 번역 — 02 학습지 「내 풀이 메모」에서 카드로 옮겨지지 않은
  말을 그대로 옮겨 적기(내 메모의 애매했던 부분 발견). 02 메모가 없는
  학생은 도입의 가상 메모를 번역
- 「갈라지는 대본」 칸 — 빨리 끝낸 학생용, 2차시 모둠 공유의 첫 순서.
  **대본과 함께 「실제로 갈라진 칸」(앱에서 확인한 것)을 반드시 적는다** —
  2차시에는 앱이 없으므로(도구 규칙) 이 기록이 맞히기 공개의 유일한 정답
  근거다
- 「한 문장 도전」 빈칸 두 줄 — 「두 로봇을 갈라놓은 카드들은 모두 ___ /
  끝까지 같게 하려면 ___」. 빈칸에 답이 될 낱말을 미리 적어 주지 않는다
- (다음 시간) 칸 — 모둠에서 비교할 것(갈라지는 대본, 예상이 빗나간 카드)

1차시에 학생이 자기 02 학습지(구글 문서 사본)를 열 수 있게 클래스룸에서
안내한다(활동 4의 재료). 학생이 쓰는 곳은 학습지 하나로 모으고, 클래스룸
본문은 짧은 안내만(02에서 확정한 방식).

**클래스룸 과제 질문** — 앱의 구체적 조작을 지목하는 형태. 질문 1·2는 학습지
안에, 질문 3은 2차시에 용어를 연결한 뒤 클래스룸으로.

1. 「하나 옮긴다」 카드에서 로봇 A와 B가 서로 다른 것을 옮겼습니다. 로봇이
   잘못한 걸까요? 그렇게 생각한 까닭은 무엇인가요?
2. 애매한 카드인데도 두 로봇이 같은 일을 한 순간이 있었나요? 그때는 왜
   같았고, 어떤 상황이었다면 달라졌을까요?
3. (2차시 후) 누가 실행해도 같아지게 순서를 적은 것을 알고리즘의 표현이라고
   합니다. 요리법이나 조립 설명서에서 사람마다 다르게 실행할 수 있는 문장을
   하나 찾아, 갈리지 않게 고쳐 쓰세요. 명령 카드 줄처럼 적어도 좋고,
   순서도로 그려도 좋습니다.

게시 시점: **질문 3을 먼저 내면 '알고리즘'이라는 답을 교사가 준 셈이 된다**
(01 질문 5, 02 질문 3과 같은 원칙). 갈라지는 대본의 모둠 맞히기는 과제가
아니라 **2차시 첫 10분 수업 활동**(1차시 학습지 (다음 시간) 칸)이다.
