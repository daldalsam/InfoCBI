# II-1-01 디지털 형태의 데이터 수업 설계

교과서(비상교육) 45~48쪽 / 폴더 `02-data/01-digital-data`

## 1. 개념적 렌즈

**렌즈:** 표현(representation)

**왜 이 렌즈인가:** 이 소단원에서 학생은 실생활 데이터가 디지털 형태로 바뀌는
원리를 배운다. 아날로그·디지털·비트를 각각 배우면 조각 지식으로 끝나지만,
'표현'이라는 렌즈로 묶으면 모두 "연속적인 실제를 컴퓨터가 다룰 수 있는 단위로
바꿔 나타낸 것"이라는 한 원리로 보인다. 표현은 교과 관통 개념표에서 데이터(핵심),
알고리즘 표현, 인공지능에 반복 등장하므로, 지금 세워두면 이후 단원에서 같은
렌즈가 깊어지는 나선형 구조가 된다. 핵심 개념 중 '이산화'는 렌즈가 아니라
일반화 문장 안의 메커니즘(연속 → 이산)으로 배치한다.

## 2. 일반화 문장

**일반화:** 디지털 표현은 연속적인 대상을 이산적인 단위로 나누어 나타내며,
단위를 잘게 나눌수록 원본에 가까워지지만 저장 공간이 늘어난다.

**점검**

- [x] 다른 단원이나 다른 교과에도 통하는가 — 소리(샘플링), 이미지(픽셀·비트),
  문자(코드 길이), 센서 데이터, AI 학습 데이터에 그대로 적용됨
- [x] 특정 도구나 프로그램 이름이 들어가 있지 않은가
- [x] "무엇이다"가 아니라 "어떻게/왜 그러한가"를 담고 있는가 —
  트레이드오프 관계를 진술함

## 3. 탐구 질문

| 종류 | 질문 |
|---|---|
| 사실적 (답이 정해진 것) | 1비트로는 몇 가지를 구분할 수 있는가? 아날로그 데이터와 디지털 데이터는 무엇이 다른가? |
| 개념적 (일반화로 이끄는 것) | 연속적인 것을 컴퓨터에 저장하려면 왜 나누어야 하는가? 더 잘게 나누면 무엇이 좋아지고 무엇을 잃는가? |
| 논쟁적 (정답이 갈리는 것) | 디지털로 바꾸면 항상 조금은 손해인데, 그래도 세상은 왜 디지털을 택했을까? |

## 4. 관련 성취기준

- [9정02-01] 실생활의 데이터가 디지털 형태로 변환되어 활용되는 긍정적 가치를
  탐색하고, 다양한 데이터를 디지털 형태로 표현한다.

## 5. 앱이 담당할 것

이 단원의 앱은 **샘플링 조작기** 하나다. 한 화면, 조작 하나(정밀도 조절)로
만들고, 이미지(픽셀 격자·비트 슬라이더)와 문자는 `02-representation`의
별도 앱이 담당한다.

**조작 대상:** 정밀도 슬라이더(샘플링 간격) — 연속 곡선 위에
채집점이 찍히는 간격을 학생이 직접 조절

**즉시 보이는 변화:** 슬라이더를 움직이면 ① 채집점 개수가 변하고
② 점만으로 복원한 계단 곡선이 원본 곡선 위에 겹쳐 그려지며
③ 저장에 필요한 숫자 개수가 함께 변함

**학생이 하는 판단:** "원본이라고 인정할 만한" 최소 간격을 스스로 정하기.
정답이 없고, 왜 그 간격이면 충분한지 근거와 함께 말하게 함

**극단값:** 채집점 2~3개(원본을 알아볼 수 없음) ↔ 최대 촘촘함(원본과 거의
일치하지만 저장 숫자가 1024개 — 2의 10제곱이라 다음 소단원의 비트와 연결됨)

## 6. 수업·클래스룸이 담당할 것

| 단계 | 어디서 | 내용 |
|---|---|---|
| 관계 맺기 | 수업 | "전화 목소리는 왜 실제와 다르게 들릴까?" / 옛날 게임 음악과 요즘 음원 비교 재생 |
| 조사하기 | 앱 | 위 5번 (곡선 모드에서 정밀도 슬라이더 조작) |

| 정리 | 수업 | 패들렛에 모인 학생 표현을 일반화 문장으로 다듬기 + 교과서 45~48쪽 용어(아날로그·디지털·비트) 연결 |

**클래스룸 과제 질문** — 앱의 구체적 조작을 지목하는 형태로 씁니다.

1. 채집점이 3개일 때와 가장 촘촘할 때, 복원된 곡선은 각각 원본과 얼마나
   닮았고 저장 숫자는 몇 개였나요?
2. 간격을 좁히면 무엇이 좋아지고 무엇을 잃었나요?
3. 여러분이 "이 정도면 원본으로 인정"이라고 정한 간격은 어디였나요?
   그렇게 정한 이유를 쓰세요.
4. 손해를 감수하면서도 세상이 데이터를 디지털로 바꾸는 이유는 무엇일까요?
   지난 시간 앱 조작에서 근거를 하나 찾아 쓰세요.
   (질문 1~3은 1차시 기록용, 질문 4는 2차시 토론 뒤 게시)

### 7.1 1차시 — 만져보고 기록하기

**수업 흐름:** 관계 맺기 → 조사하기(앱) → 발견 기록

**준비물:** 학생 기기, 앱 주소, 클래스룸 과제(질문 1~3), 음질 비교용
음원 2개, 도입 답을 모을 패들렛

| 시간 | 단계 | 교사가 하는 일 |
|---|---|---|
| 0~8분 | 관계 맺기 | 옛날 게임 음악이나 저음질 음원과 요즘 음원을 이어서 들려준다. “두 소리는 뭐가 다를까? 왜 다르게 들릴까?”, “전화 속 목소리는 왜 실제 목소리와 다르게 들릴까?”라고 묻는다. 학생이 답을 패들렛에 직접 올리게 하고 판단하거나 정리하지 않는다. 이 답은 2차시 용어 연결에서 다시 사용한다. |
| 8~13분 | 앱 열기 | 앱 주소를 안내하고 3분 동안 설명 없이 자유롭게 조작하게 한다. |
| 13~28분 | 조사하기 | ① 슬라이더를 양 끝으로 밀어 변화를 관찰한다. ② 점이 2~3개일 때 복원된 파란 선이 원본 회색 선을 얼마나 따라가는지 살펴본다. ③ “원본이라고 인정할 만한” 최소 간격을 스스로 정한다. 미션 1은 학습지 활동 1, 미션 3은 활동 2에 바로 기록하게 한다. |
| 28~40분 | 기록 | 앱에서 직접 본 것을 근거로 학습지 질문 1~3을 작성한다. 이어서 ‘~할수록 ~하다’ 꼴의 한 문장 도전을 채우고, 다 쓴 학생은 짝과 답을 비교한다. |
| 40~45분 | 마무리 | “오늘 발견한 것에 이름은 붙이지 않을게. 다음 시간에 여러분 기록을 모아서 정체를 밝혀보자.”라고 안내하고 마친다. |

**조사하기에서 사용할 발문**

- “방금 슬라이더를 왼쪽으로 밀었을 때 뭘 잃었어?”
- “점 몇 개면 충분하다고 정했어? 왜 거기야?”
- “점을 늘리면 공짜야? 화면에서 같이 변하는 숫자가 있는지 봐.”

**예상 반응과 대응**

- “점이 많을수록 좋은 거 아니에요?” → “그럼 무한히 늘리면 어떻게 될까?
  저장할 숫자 개수를 봐.”
- “몇 개가 정답이에요?” → “정답이 없어. 네가 정하고 이유를 말하는 게
  오늘 과제야.”
- 일찍 끝낸 학생은 점 개수를 절반으로 줄여도 차이가 잘 보이지 않는 곡선
  구간을 찾게 한다.

**수업에서 유의할 점**

- ‘디지털’, ‘샘플링’, ‘아날로그’라는 용어를 교사가 먼저 말하지 않는다.
- 앱 조작 전에 원리를 설명하지 않는다.
- 학생이 정한 “충분한 간격”을 정답처럼 평가하지 않는다.

### 7.2 2차시 — 이름 붙이고 넓히기

**수업 흐름:** 패턴 말하기 → 일반화와 용어 정리 → 토론 → 전이

**준비물:** 1차시 기록, 확대하면 픽셀이 보이는 사진 1장, 2차시 학습지,
모둠 문장용 패들렛, 1차시 답 모음 패들렛 링크

| 시간 | 단계 | 교사가 하는 일 |
|---|---|---|
| 0~10분 | 패턴 말하기 | 모둠별로 1차시 기록을 비교하고 공통점을 찾는다. “모둠의 발견을 ‘~할수록 ~하다’ 꼴의 한 문장으로 만들어 봐.”라고 안내한다. 모둠 문장은 패들렛의 모둠 칼럼에 올린다. |
| 10~22분 | 일반화 다듬기 | 패들렛 문장에서 공통 구조를 찾아 학급 문장으로 다듬는다. 학생이 쓴 단어를 최대한 남기고 빠진 내용은 발문으로 찾게 한다. 완성한 문장은 새 게시물로 올려 고정한다. |
| 22~32분 | 용어 연결 | 학생이 발견한 내용에 아날로그, 디지털, 샘플링, 비트라는 교과서 용어를 연결한다. 1차시 도입 패들렛을 다시 보여 주고 전화 목소리가 다르게 들리는 이유를 이제 설명할 수 있는지 묻는다. |
| 32~40분 | 토론 | “디지털로 바꾸면 항상 조금은 손해라는 걸 발견했지. 그런데 세상은 왜 디지털을 택했을까?”라고 묻는다. 복사·전송·보관의 장점이 나오도록 돕고 질문 4 과제를 안내한다. |
| 40~45분 | 전이 | 사진을 크게 확대해 픽셀이 보이게 한다. “소리는 시간을 점으로 나눴어. 그럼 이 사진은 무엇을 나눈 걸까?”라고 묻고 답을 정리하지 않은 채 다음 소단원을 예고한다. |

**일반화 다듬기에서 사용할 발문**

- “좋아지는 얘기는 다 있는데, 대신 치르는 값은 어느 문장에 있지?”
- “어제 여러분이 슬라이더로 한 일이 바로 샘플링이야. 발견은 이미 했고,
  오늘은 이름만 배운 거야.”
- “수업 전에 전화 목소리가 왜 다르게 들릴지 추측했지. 이제 답할 수 있겠어?”

**예상 반응과 대응**

- 모둠 문장이 “점이 많으면 비슷해진다”처럼 사실 나열에 그치면 “소리 말고
  다른 것에도 통하는 문장으로 넓혀 볼까?”라고 묻는다.
- 학급 문장이 매끄럽지 않아도 교사가 준비한 문장으로 바꾸지 않는다. 이후
  단원에서 같은 개념을 다시 만나며 다듬을 수 있다.

**수업에서 유의할 점**

- 모둠 문장을 교사가 준비한 일반화 문장으로 교체하지 않는다.
- 용어 설명은 학생의 발견 뒤에 짧게 한다.
- 사진에서 무엇을 나눈 것인지 교사가 답하지 않는다. 다음 소단원에서 이어서
  탐구한다.
