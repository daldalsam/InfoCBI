# II-1-02 다양한 데이터의 디지털 표현 수업 설계

교과서(비상교육) 48~55쪽 / 폴더 `02-data/02-representation`

## 1. 개념적 렌즈

**렌즈:** 표현(representation)

**왜 이 렌즈인가:** 01-digital-data에서 세운 렌즈를 그대로 이어받는다.
01이 "연속을 이산으로 바꾼다"는 표현의 원리를 곡선 하나로 보았다면,
이 단원은 문자·이미지·소리라는 서로 다른 매체에 그 원리가 어떻게 적용되는지,
그리고 그 적용을 가능하게 하는 것(약속)이 무엇인지를 본다.
같은 렌즈가 두 번째 등장하면서 깊어지는 나선형 구조다.
(pedagogy.md 점검: 같은 렌즈가 반복 등장 — 정상)

## 2. 일반화 문장

**일반화 1 (본체, 이 단원에서 새로 깊어지는 것):**
서로 다른 종류의 데이터도 같은 비트로 표현할 수 있는 것은 대상과 비트 사이에
약속(규칙)을 정해 두었기 때문이며, 같은 비트라도 약속이 다르면 다른 의미가 된다.

**일반화 2 (01에서 이어받아 반복·확인하는 것):**
표현의 정밀도를 높이면 원본에 가까워지지만 저장 공간이 늘어난다 —
이 관계는 문자·이미지·소리 어디서나 성립한다.

**점검**

- [x] 다른 단원이나 다른 교과에도 통하는가 — 일반화 1은 알고리즘 표현,
  AI의 데이터 표현, 파일 형식, 언어 기호(국어)까지 통함. 일반화 2는 01에서
  검증된 문장의 매체 확장
- [x] 특정 도구나 프로그램 이름이 들어가 있지 않은가
- [x] "무엇이다"가 아니라 "어떻게/왜 그러한가"를 담고 있는가 —
  둘 다 관계 진술("~때문이며", "~하면 ~진다")

## 3. 탐구 질문

| 종류 | 질문 |
|---|---|
| 사실적 (답이 정해진 것) | 문자 'A'의 코드값은 무엇인가? 8×8 픽셀 격자 하나를 저장하려면 몇 비트가 필요한가? |
| 개념적 (일반화로 이끄는 것) | 같은 0과 1의 나열이 어떻게 어떤 때는 글자가 되고 어떤 때는 그림이 되는가? 약속이 서로 다르면 무슨 일이 벌어지는가? |
| 논쟁적 (정답이 갈리는 것) | 세상 모든 글자와 기호를 하나의 약속에 담아야 할까, 나라마다·용도마다 다른 약속을 써도 될까? |

## 4. 관련 성취기준

- [9정02-01] 실생활의 데이터가 디지털 형태로 변환되어 활용되는 긍정적 가치를
  탐색하고, 다양한 데이터를 디지털 형태로 표현한다.

같은 기준이 01·02 두 소단원에 걸쳐 있다. 01이 "긍정적 가치 탐색"을,
02가 "다양한 데이터를 디지털 형태로 표현한다"를 주로 담당한다.

## 5. 앱이 담당할 것

이 단원의 앱은 **비트 해석 전환기** 하나다. 한 화면, 조작 하나.
01의 샘플링 조작기와 별개의 앱이며, 트레이드오프(일반화 2)는 이 앱이 아니라
클래스룸 과제(4번 질문)와 교과서 연결로 다룬다.

**조작 대상:** 8×8 격자(64비트)의 칸을 켜고 끄기. 터치로도 조작 가능

**즉시 보이는 변화:** 같은 64비트를 세 가지 약속으로 읽은 결과가 나란히
동시 갱신 — ① 그림으로: 1비트 흑백 이미지 ② 글자로: 한 행(8비트)씩
문자 코드로 읽은 8글자 ③ 수로: 각 행을 이진수→십진수로 읽은 8개의 수

**학생이 하는 판단:** 어떤 약속을 기준으로 비트를 맞출지 선택하기 —
자기 이니셜이 나오게 맞추기 / 그림 그리기 / 둘을 동시에 만족시킬 수 있는지
실험하기. 동시 만족은 대부분 실패하며, 그 실패에서 "비트는 하나인데
약속마다 요구가 다르다"를 발견하게 한다

**극단값:** 모두 0 / 모두 1일 때 세 해석이 각각 무엇이 되는지.
딱 한 비트만 바꿨을 때 세 해석이 제각각 어떻게 달라지는지

## 6. 수업·클래스룸이 담당할 것

| 단계 | 어디서 | 내용 |
|---|---|---|
| 관계 맺기 | 수업 | 깨진 글자(뷁, ▯▯▯) 스크린샷 — "왜 이렇게 보일까?" + 01 전이 회수(사진 확대에서 본 픽셀) |
| 조사하기 | 앱 | 위 5번 (격자 비트를 켜고 끄며 세 해석 비교) |
| 패턴 말하기 | 클래스룸·패들렛 | "같은 격자인데 해석이 왜 다른가"를 문서에 적고, 모둠 문장은 패들렛에 공유 |
| 정리 | 수업 | 패들렛에 모인 학생 표현 → 일반화 1로 다듬기 + 교과서 48~55쪽 용어(문자 코드, 픽셀, 비트 수, 샘플링) 연결 |
| 전이 | 수업 | 같은 파일을 텍스트로/이미지로 열어보는 시연 — "확장자가 바로 약속 표시" + 다음 영역(데이터 분석) 예고 |

**클래스룸 과제 질문** — 앱의 구체적 조작을 지목하는 형태로 씁니다.

1. 격자를 모두 0, 모두 1로 했을 때 글자·수·그림 해석은 각각 무엇이었나요?
2. 원하는 글자가 나오게 비트를 맞췄을 때 그림 해석은 어떤 모습이었나요?
   그림과 글자를 동시에 원하는 대로 만들 수 있었나요? 왜 그럴까요?
3. 같은 비트인데 해석이 달라지는 이유를 '약속'이라는 말을 써서 설명해 보세요.
4. 01 앱에서 발견한 "잘게 나눌수록 원본에 가깝지만 저장 공간이 늘어난다"는
   관계가 이미지의 비트 수에서도 성립하나요? 오늘 실습에서 예를 찾아
   설명하세요. (픽셀 하나에 쓰는 비트 수를 늘리면 무엇이 좋아지고 무엇이
   늘어나는지)

게시 시점: 질문 1~2는 1차시 기록용, 질문 3은 **2차시에 학급 문장을 만든 뒤**,
질문 4는 3차시 실습 뒤. 질문 3을 먼저 내면 '약속'이라는 답을 교사가 준 셈이
됩니다.

## 7. 차시 계획

| 차시 | 활동 | 사용 도구 |
|---|---|---|
| 1 | 관계 맺기(깨진 글자 질문) → 앱 조작: 세 해석 비교, 극단값·한 비트 실험, 이니셜/그림 동시 만족 도전 → 발견 기록(과제 질문 1~2) | 앱, 클래스룸 |
| 2 | 모둠별 기록 공유 → 학생 표현 모아 일반화 1 다듬기(과제 질문 3 안내) → 교과서 용어 연결 → 토론 "하나의 약속에 담아야 할까?" → 전이: 같은 파일 다르게 열기 시연 | 클래스룸, 교과서 |
| 3 | 교과서 실습: 문자·이미지·소리를 직접 디지털로 표현하기(48~55쪽 활동) + 과제 질문 4(일반화 2를 이미지 비트 수로 확인) | 교과서, 클래스룸 |

### 7.1 1차시 — 같은 격자, 다른 해석

**수업 흐름:** 관계 맺기 → 조사하기(앱) → 발견 기록

**준비물:** 학생 기기, 앱 주소, 깨진 글자 화면, 앞 단원에서 사용한 확대
사진, 질문 1~2 학습지, 도입 답을 모을 패들렛

| 시간 | 단계 | 교사가 하는 일 |
|---|---|---|
| 0~8분 | 관계 맺기 | 깨진 글자 화면을 보여 주고 “이 글자는 원래 뭐였을까? 왜 이렇게 보이는 걸까?”라고 묻는다. 앞 단원의 사진 확대 장면을 떠올리며 사진은 무엇을 나눈 것인지 질문한다. 학생 답은 정리하지 않고 패들렛에 모은다. |
| 8~12분 | 앱 열기 | 앱 주소를 안내하고 설명 없이 자유롭게 조작하게 한다. 세 결과가 함께 변한다는 사실을 학생이 발견하면 학급에 공유한다. |
| 12~30분 | 조사하기 | ① 모두 0과 모두 1 비교 ② 한 칸만 바꾸기 ③ 수 칸에 65 만들기 ④ 글자 칸에 이니셜 만들기 ⑤ 격자에 그림 그리기 ⑥ 글자와 그림을 동시에 원하는 모양으로 만드는 도전을 차례로 제시한다. 미션 1·2는 학습지 활동 1·2, 미션 3~6은 활동 3에 기록한다. |
| 30~40분 | 기록 | 앱에서 직접 본 것을 근거로 질문 1~2를 작성한다. 이유를 아직 설명하지 못해도 다음 시간에 함께 해결할 문제임을 알려 준다. |
| 40~45분 | 마무리 | “같은 64칸인데 세 가지로 읽혔어. 읽는 방법에 이름을 붙일 수 있을까?”라고 묻고 답을 설명하지 않은 채 마친다. |

**조사하기에서 사용할 발문**

- “왜 안 될까? 비트는 하나뿐인데 네가 원하는 건 몇 가지야?”
- “글자 칸은 이 비트를 어떻게 읽고 있는 것 같아?”
- “읽는 방법이 세 개인데, 방법을 정한 건 누구야?”

**예상 반응과 대응**

- 글자가 이상한 기호로 나오면 도입에서 본 깨진 글자와 비슷한지 묻는다.
- 글자와 그림을 동시에 만드는 방법을 요구하면 해결법 대신 왜 어려운지가
  오늘의 문제라고 안내한다.
- 이니셜 만들기에 성공한 학생은 그림 칸을 캡처하여 2차시 비교 자료로 남긴다.
- 일찍 끝낸 학생은 한 행만 남기고 나머지를 0으로 만들어 수 칸의 규칙을
  찾아보게 한다.

**수업에서 유의할 점**

- ‘약속’, ‘규칙’, ‘인코딩’을 교사가 먼저 말하지 않는다.
- 동시 만족이 어려운 이유를 미리 설명하지 않는다.
- 문자 코드표는 2차시 용어 연결 전에 보여 주지 않는다.
- ‘약속’이라는 말이 들어 있는 질문 3은 이 차시에 게시하지 않는다.

**클래스룸 과제**

1차시 시작 전에 질문 1~2만 게시한다. 실제 수업에서는 `[앱 주소]`를 배포한
주소로 바꾼다.

**패들렛 준비**

- 학생은 실명 대신 모둠 이름이나 번호를 사용한다.
- 2차시 토론에서 다시 사용하므로 게시물을 남겨 둔다.

### 7.2 2차시 — 약속에 이름 붙이기

**수업 흐름:** 패턴 말하기 → 일반화와 용어 정리 → 토론 → 전이

**준비물:** 1차시 기록, 문자 코드표, 같은 파일을 두 방식으로 열어 볼 준비,
2차시 학습지, 모둠 문장용 패들렛, 1차시 답 모음 패들렛

| 시간 | 단계 | 교사가 하는 일 |
|---|---|---|
| 0~10분 | 패턴 말하기 | 1차시 기록을 비교하고 글자와 그림을 동시에 원하는 대로 만들기 어려웠던 이유를 “같은 비트인데 ~하기 때문이다”라는 문장으로 만든다. 모둠 문장과 관련 화면을 패들렛에 올린다. |
| 10~20분 | 일반화 다듬기 | 게시물의 공통 구조를 찾아 학급 문장으로 다듬는다. “읽는 방법은 누가, 언제 정한 것일까?”, “정해 두지 않았다면 어떻게 될까?”라고 묻고 학생 표현을 최대한 남긴다. 완성 문장은 패들렛에 고정하고 질문 3을 안내한다. |
| 20~30분 | 용어 연결 | 학생의 발견에 문자 코드, 픽셀, 비트 수, 샘플링이라는 교과서 용어를 연결하고 문자 코드표를 처음 보여 준다. |
| 30~38분 | 토론 | 1차시 도입 답을 다시 보여 주고 깨진 글자의 이유를 설명하게 한다. 이어서 “세상 모든 글자를 하나의 약속에 담는 게 좋을까?”를 토론한다. 하나의 약속이 주는 장점과 용량·호환의 문제를 함께 살핀다. |
| 38~45분 | 전이 | 같은 파일을 텍스트 편집기와 이미지 뷰어로 열어 보여 준다. 확장자가 비트를 읽는 방법과 어떤 관계인지 학생이 설명하게 하고 3차시를 예고한다. |

**예상 반응과 대응**

- “글자와 그림은 다르다”에서 멈추면 비트는 같은데 무엇이 다른지 묻는다.
- ‘약속’이라는 말이 나오지 않아도 ‘미리 정한 것’, ‘규칙’, ‘읽는 법’ 같은
  학생 표현을 먼저 사용하고 용어 연결 단계에서 이름을 붙인다.
- 토론이 한쪽으로 쏠리면 교사가 반대 의견을 제시하지 않고 다른 생각이 있는
  학생을 찾는다.

**수업에서 유의할 점**

- 학생 문장을 교사가 준비한 일반화로 교체하지 않는다.
- 문자 코드표는 일반화 문장을 만든 뒤 제시한다.
- 논쟁적 질문의 결론을 교사가 정하지 않는다.

### 7.3 3차시 — 직접 표현해보기

**수업 흐름:** 교과서 실습 → 일반화 2 확인

**준비물:** 교과서, 학생 기기, 2차시 학급 문장 패들렛, 3차시 학습지,
문자·이미지·소리 비교용 패들렛

| 시간 | 단계 | 교사가 하는 일 |
|---|---|---|
| 0~5분 | 연결 | 2차시에 만든 학급 문장을 다시 보여 주고 문자·그림·소리에 모두 적용되는지 직접 확인할 것임을 안내한다. |
| 5~35분 | 실습 | 교과서의 문자·이미지·소리 표현 활동을 진행한다. 모둠별로 매체를 나누어 맡고 서로 설명하게 할 수 있다. 각 매체에서 약속에 해당하는 것, 정밀도를 높이기 위해 늘려야 할 것, 그때 함께 커지는 것을 묻는다. |
| 35~45분 | 일반화 확인 | 문자·이미지·소리에서 늘리면 커지는 것을 패들렛 칼럼에 올려 비교한다. 샘플 수, 픽셀·비트 수, 문자 종류가 늘면 저장 용량도 늘어나는 공통점을 찾고 질문 4를 안내한다. 마지막에는 다음 단원에서 저장한 데이터를 분석한다는 점을 예고한다. |

**실습에서 사용할 발문**

- “여기서 약속에 해당하는 것은 뭐야?”
- “더 정밀하게 하려면 무엇을 늘려야 해? 늘리면 뭐가 커져?”
- “앞 단원에서 소리로 발견한 관계가 그림과 글자에도 있었네. 여러 단원에
  통하는 이런 문장을 무엇이라고 할 수 있을까?”

**예상 반응과 대응**

- 매체별 소요 시간 차이가 크면 모둠별로 매체를 나누어 맡긴다. 모두 해야
  한다면 시간이 오래 걸리는 소리를 마지막에 배치한다.
- 앱에서 이미 본 내용이라고 하면 앱의 경험이 교과서 어디에 나오는지 찾게 한다.
- 시간이 부족하면 일반화 확인을 질문 4로 이어서 쓰고 다음 단원 첫 시간에
  다시 확인한다.

**수업에서 유의할 점**

- 실습을 절차 따라 하기로 끝내지 않고 매체가 바뀔 때마다 약속을 찾게 한다.
- 일반화 2를 교사가 먼저 정리하지 않고 세 매체의 결과를 비교해 학생이
  연결하게 한다.
