# 교과서 단원 구성

**출처**: 중학교 정보 (비상교육) / 임희석·김형기·서성원·김장환·최정원·조재춘
2022 개정 교육과정

목차 정보만 정리한 문서입니다. 교과서 본문 내용은 출판사 저작물이므로 이 저장소에
포함하지 않습니다.

## 구조

대단원 5개 → 중단원 2개씩 → 소단원.
각 중단원 끝에 「핵심 콕콕 정리하기」, 대단원 끝에 「창의와 혁신으로 만드는 세상」,
「과정 중심의 수행 활동」, 「확인 꼭꼭 단원 평가하기」가 반복됩니다.
이 고정 코너들은 별도 폴더를 만들지 않습니다.

**앱 적합도** ◎ 우선 개발 / ○ 보조 도구 / △ 앱보다 다른 활동이 나음
(근거는 `docs/curriculum.md` 참고)

**앱을 만들 단원만** 폴더를 만듭니다. 나중에 필요해지면 추가하면 됩니다.

# 개발 순서

적합도 ◎만 추린 목록입니다. 위에서부터 만드는 것을 권합니다.

| 순서 | 교과서 단원 | 폴더 | 만들 것 |
|---|---|---|---|
| 1 | II-1-01·02 데이터의 표현 | `02-data/01-digital-data`, `02-representation` | 픽셀 격자, 비트 수 슬라이더, 샘플링 |
| 2 | III-2-02 논리 연산 | `03-algorithm-programming/05-logic` | 스위치 조작 + 진리표 자동 완성 |
| 3 | III-2-03 중첩 제어 구조 | `.../06-nested-control` | 반복 실행 순서 시각화 |
| 4 | III-2-04 리스트 | `.../07-list` | 배열 칸에 값 넣고 빼고 찾기 |
| 5 | III-1-04 알고리즘 분석 | `.../04-analysis` | 정렬·탐색 나란히 비교 |
| 6 | III-1-02 추상화 | `.../02-abstraction` | 정보 걷어내기 실험 |
| 7 | IV-1-02 데이터와 학습 | `04-ai/02-data-learning` | 편향 실험기 |
| 8 | I-1-01 컴퓨팅 시스템 | `01-computing-system/01-system-structure` | 자원 할당 시뮬레이터 |

**1번을 첫 앱으로 권합니다.** 교과서 45~55쪽이고, 조작 대상이 눈에 잘 보이며,
이후 소리·문자로 전이가 자연스럽습니다.

# 참고

교육과정에 "내용 영역의 배열순서가 반드시 교수·학습의 순서를 의미하는 것은 아니므로
내용이나 순서 등을 재구성할 수 있다"고 명시돼 있습니다.
폴더를 교과서 순서로 잡고 수업도 그 순서로 진행해도 무방합니다.
