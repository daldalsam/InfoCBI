Ⅱ-1-01 디지털 형태의 데이터

2차시 앱 사용 가능

성취기준

[9정02-01] 실생활의 데이터가 디지털 형태로 변환되어 활용되는 긍정적 가치를 탐색하고, 다양한 데이터를 디지털 형태로 표현한다.
— 01·02 두 소단원이 나눠 맡음. 01은 "긍정적 가치 탐색" 쪽.

개념적 렌즈와 일반화

렌즈: 표현 — 학생이 스스로 이 문장에 도달하는 것이 목표입니다. 먼저 말하지 않습니다.

디지털 표현은 연속적인 대상을 이산적인 단위로 나누어 나타내며, 단위를 잘게 나눌수록 원본에 가까워지지만 저장 공간이 늘어난다.

탐구 질문

사실적1비트로는 몇 가지를 구분할 수 있는가? 아날로그 데이터와 디지털 데이터는 무엇이 다른가?
개념적연속적인 것을 컴퓨터에 저장하려면 왜 나누어야 하는가? 더 잘게 나누면 무엇이 좋아지고 무엇을 잃는가?
논쟁적디지털로 바꾸면 항상 조금은 손해인데, 그래도 세상은 왜 디지털을 택했을까?

앱 — 샘플링 조작기

점 몇 개면 될까? 열기

정밀도 슬라이더 하나로 채집점 개수·복원 곡선·저장할 숫자 개수가 즉시 변합니다. 학생이 하는 판단: "원본이라고 인정할 만한" 최소 간격을 스스로 정하고 근거 말하기. 정답 없음. 오차 수치도 일부러 넣지 않았습니다(수치를 주면 그 수치를 맞추는 게임이 됩니다).

수업 흐름 — 앱은 조사하기만 담당

관계 맺기수업"전화 목소리는 왜 실제와 다르게 들릴까?" / 옛날 게임 음악과 요즘 음원 비교 재생
조사하기앱정밀도 슬라이더 실험, 극단값 확인
패턴 말하기클래스룸"간격을 좁힐수록/넓힐수록 무엇이 어떻게 변했나" 기록, 모둠 공유
정리수업학생 표현을 모아 일반화로 다듬기 + 교과서 용어(아날로그·디지털·비트) 연결
전이수업"이미지도 같은 방식일까?" — 사진을 확대해 픽셀을 보여주며 02 예고

클래스룸 과제 질문 (복사해서 쓰기)

  1. 채집점이 3개일 때와 가장 촘촘할 때, 복원된 곡선은 각각 원본과 얼마나 닮았고 저장 숫자는 몇 개였나요?
  2. 간격을 좁히면 무엇이 좋아지고 무엇을 잃었나요?
  3. 여러분이 "이 정도면 원본으로 인정"이라고 정한 간격은 어디였나요? 그렇게 정한 이유를 쓰세요.
  4. 손해를 감수하면서도 세상이 데이터를 디지털로 바꾸는 이유는 무엇일까요? 오늘 조작에서 근거를 하나 찾아 쓰세요.

차시 계획

1차시관계 맺기(전화 목소리·게임 음악) → 앱 조작: 슬라이더 실험, 극단값, "충분한 간격" 정하기 → 발견 기록(과제 1~3) — 앱, 클래스룸
2차시모둠 공유 → 일반화 다듬기 → 교과서 용어 연결 → 토론 "디지털이 항상 나은가?"(과제 4) → 전이: 픽셀 보여주며 02 예고 — 클래스룸, 교과서

→ 차시별 상세 지도안 보기 (시간 배분·발문·예상 반응·유의점)

Ⅱ-1-02 다양한 데이터의 디지털 표현

3차시 앱 사용 가능

성취기준

[9정02-01] 실생활의 데이터가 디지털 형태로 변환되어 활용되는 긍정적 가치를 탐색하고, 다양한 데이터를 디지털 형태로 표현한다.
— 02는 "다양한 데이터를 디지털 형태로 표현한다" 쪽.

개념적 렌즈와 일반화

렌즈: 표현 — 01에서 세운 렌즈가 두 번째 등장하며 깊어집니다.

① 서로 다른 종류의 데이터도 같은 비트로 표현할 수 있는 것은 대상과 비트 사이에 약속(규칙)을 정해 두었기 때문이며, 같은 비트라도 약속이 다르면 다른 의미가 된다.
② (01에서 이어받아 확인) 표현의 정밀도를 높이면 원본에 가까워지지만 저장 공간이 늘어난다 — 문자·이미지·소리 어디서나 성립.

탐구 질문

사실적문자 'A'의 코드값은 무엇인가? 8×8 픽셀 격자 하나를 저장하려면 몇 비트가 필요한가?
개념적같은 0과 1의 나열이 어떻게 어떤 때는 글자가 되고 어떤 때는 그림이 되는가? 약속이 서로 다르면 무슨 일이 벌어지는가?
논쟁적세상 모든 글자와 기호를 하나의 약속에 담아야 할까, 나라마다·용도마다 다른 약속을 써도 될까?

앱 — 비트 해석 전환기

그림일까, 글자일까, 수일까? 열기

8×8 격자(64비트)를 켜고 끄면 같은 비트가 세 가지 약속(그림·글자·수)으로 읽힌 결과가 나란히 즉시 갱신됩니다. 학생이 하는 판단: 어떤 약속을 기준으로 비트를 맞출지 선택 — 이니셜 만들기, 그림 그리기, 둘의 동시 만족 도전(대부분 실패하며 거기서 발견이 나옵니다). 화면에는 '약속'이라는 단어를 일부러 쓰지 않았습니다 — 학생이 도달해야 할 말이라서요. 드래그로 여러 칸을 한 번에 칠할 수 있고, "모두 0 / 모두 1" 버튼이 극단값 관찰용입니다.

수업 흐름 — 앱은 조사하기만 담당

관계 맺기수업깨진 글자(뷁, ▯▯▯) 스크린샷 — "왜 이렇게 보일까?" + 01 전이 회수(사진 확대에서 본 픽셀)
조사하기앱격자 비트를 켜고 끄며 세 해석 비교
패턴 말하기클래스룸"같은 격자인데 해석이 왜 다른가" 기록, 모둠 공유
정리수업학생 표현 → 일반화 ①로 다듬기 + 교과서 용어(문자 코드, 픽셀, 비트 수, 샘플링) 연결
전이수업같은 파일을 텍스트로/이미지로 열어보는 시연 — "확장자가 바로 약속 표시" + 다음 영역(데이터 분석) 예고

클래스룸 과제 질문 (복사해서 쓰기)

  1. 격자를 모두 0, 모두 1로 했을 때 그림·글자·수 해석은 각각 무엇이었나요?
  2. 원하는 글자가 나오게 비트를 맞췄을 때 그림 해석은 어떤 모습이었나요? 그림과 글자를 동시에 원하는 대로 만들 수 있었나요? 왜 그럴까요?
  3. 같은 비트인데 해석이 달라지는 이유를 '약속'이라는 말을 써서 설명해 보세요.
  4. 01 앱에서 발견한 "잘게 나눌수록 원본에 가깝지만 저장 공간이 늘어난다"는 관계가 이미지의 비트 수에서도 성립하나요? 교과서에서 예를 찾아 설명하세요.

차시 계획

1차시관계 맺기(깨진 글자) → 앱 조작: 세 해석 비교, 극단값·한 비트 실험, 동시 만족 도전 → 발견 기록(과제 1~3) — 앱, 클래스룸
2차시모둠 공유 → 일반화 ① 다듬기 → 교과서 용어 연결 → 토론 "하나의 약속에 담아야 할까?" → 전이: 같은 파일 다르게 열기 시연 — 클래스룸, 교과서
3차시교과서 실습: 문자·이미지·소리를 직접 디지털로 표현하기(교과서의 표현 활동) + 과제 4(일반화 ②를 이미지 비트 수로 확인) — 교과서, 클래스룸

→ 차시별 상세 지도안 보기 (시간 배분·발문·예상 반응·유의점)
